# Blockchain

<p style="font-size: 15px">
این پروژه یک پیاده‌سازی ساده و آموزشی از بلاک‌چین است که با زبان پایتون و فریمورک جنگو توسعه داده شده است.
هدف از این پروژه، یادگیری مفاهیم پایه‌ای بلاک‌چین مانند ساختار بلاک‌ها، هش‌گذاری، اثبات کار و غیره می‌باشد
</p>

## ویژگی ها

- ساختار داده‌ای بلاک‌ها با هش قبلی و بعدی
- الگوریتم هش‌گذاری SHA-256
- مکانیسم ساده اثبات کار (PoW)
- اعتبارسنجی زنجیره بلاک‌ها
- API ساده برای تعامل با بلاک‌چین
